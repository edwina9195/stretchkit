# StretchKit 작업 인계 기록

지금까지 Claude와 진행한 대화와 결정을 정리한 문서예요. 다른 AI 도구(Codex 등)나 사람이 이어받을 때 이 파일과 루트의 `AGENTS.md`를 먼저 읽으면 됩니다.

- 제작자: **@sxdrv.mp3** (https://www.instagram.com/sxdrv.mp3/)
- 저장소: https://github.com/edwina9195/stretchkit (공개, GPLv3)
- 작업 기간: 2026-11-04
- 현재 상태: 맥(Universal)·윈도우 빌드 모두 성공, 테스트 3종 통과. 릴리스 페이지는 아직 공개 전.

## 1. 대화 흐름과 결정 사항

| 순서 | 요청 | 결정 / 결과 |
|---|---|---|
| 1 | 세라토 샘플의 타임스트레치를 그대로 가져와 내 플러그인으로 | 불가(독점 알고리즘, 리버스 엔지니어링은 라이선스 위반). 공개 라이브러리로 직접 구현하기로 |
| 2 | 드럼에 가장 자연스러운 것 | Rubber Band + "어택은 원본, 꼬리만 스트레치"(Hybrid) 방식 채택 |
| 3 | 무료 배포, VST/VST3/AU, 맥·윈도우 | VST2는 Steinberg가 신규 라이선스를 안 줘서 제외. VST3 + AU + Standalone |
| 4 | 소스 공개 여부 | **공개** 선택 → Rubber Band(GPL)를 무료로 쓸 수 있음 |
| 5 | 루프 불러오기가 아닌 트랙 FX로, 샘플 기준 % 조절 | 트랙 FX는 연속 스트레치가 물리적으로 불가(뒤처짐/미래 소리 필요) → 구간·타격 단위만 가능하다고 설명 |
| 6 | XO와 함께 실시간 드럼 스트레치 | MIDI 간격 조절 / 타격 단위 FX / 오프라인 렌더 세 가지 안내 |
| 7 | XO식 샘플 분류 + 드럼 타임스트레치를 합친 플러그인 | **악기(샘플러) 플러그인**으로 결정. 미리 계산하므로 지연 없음 |
| 8 | 시퀀서까지(3번) | 8트랙 스텝 시퀀서 포함해 1차 완성 |
| 9 | 디지코어 / Y2K / PS2 느낌 분석 | 핀터레스트·자료 조사 후 4가지 스킨(PS2 Night, Y2K Chrome, Digicore, Mix) 실제 구현 |
| 10 | 리퀴드 크롬 아이콘 이미지(참고 이미지 제공) | 직접 만든 3D 렌더러(`tools/chrome_icons.py`)로 아이콘 15개 제작. 원본 아이콘은 복제하지 않고 같은 스타일로 새로 디자인. 5번째 스킨 **Liquid Chrome** 추가 |
| 11 | 스킨 선택 기능 + 맥·윈도우 빌드 | 상단 SKIN 메뉴, 마지막 선택 기억. GitHub Actions로 빌드 |
| 12 | GitHub 연결 | 저장소 `edwina9195/stretchkit` 생성·연결. 저장소 라이선스가 GPLv3로 만들어져 문서를 GPLv3로 맞춤 |
| 13 | 설명서 + 설치법 PDF, 영어/한국어 | `docs/manual/StretchKit_Manual_EN.pdf`, `_KO.pdf`. 크레딧 @sxdrv.mp3, 플러그인 제작자명도 `sxdrv.mp3` |
| 14 | 실제 사용 피드백(12만 개 샘플) | 아래 2장 참고: 지도 개편, 드래그 재생, 유사도 바, 저장 방식, 트랙 소리 버그 수정 |
| 15 | XO 분류 알고리즘 파악 | 비공개라 정확히는 불가. 공개 정보: t-SNE로 유사도 배치 + t-SNE를 흉내 내는 신경망, 특징값은 비공개 |
| 16 | XO에 타임스트레치만 추가 / FX로 만들기 | XO 수정은 불가(비공개 상용). 대안: XO 뒤에 거는 **타격 단위 스트레치 FX** (아직 안 만듦) |

## 2. 사용자 피드백으로 고친 것 (12만 개 라이브러리 사용 중)
1. **LENGTH·PITCH가 안 들림** → 버그였음. 트랙 이름 클릭이 원본 파일을 재생하고 있었음. 이제 트랙의 실제(스트레치된) 소리를 재생하고, 슬라이더를 놓으면 렌더 완료 후 자동 재생 (`auditionTrack`).
2. **지도가 박스처럼 뭉쳐 아무것도 못 함** → 하나의 구름 지도, 픽셀 캐시 렌더링(10만+ 점), 점 크기 자동 조절.
3. **XO 같은 기능** → 유사도 바(가장 비슷한 24개, 연속 재생, 히스토리, 하트, 넣기), 검색, 즐겨찾기 필터.
4. **드래그로 샘플 재생** → 클릭한 채 드래그하면 지나가는 소리 재생(35ms 간격, 크로스페이드), 지도 밖 트랙까지 끌면 로드.
5. **매번 다시 로드됨** → 원인: 예전엔 스캔이 끝나야만 저장. 이제 폴더 즉시 저장, 4000개마다 진행 저장, 중간에 꺼도 다음에 이어서 스캔, 바이너리 캐시, 멀티코어 분석. (저장 형식이 바뀌어 새 버전 첫 실행 때 한 번 다시 스캔)

## 3. 현재 기능 요약
- 샘플 지도: 이름 → 소리 순 자동 분류(Kick/Snare/Clap/Hat/Cymbal/Tom/Perc/Other), 카테고리별 PCA → 둥근 구름 배치
- 드럼 타임스트레치: LENGTH 25~400%, Hybrid / Smooth / Tape, PITCH ±24반음, 백그라운드 렌더
- 시퀀서: 8트랙 × 8/16/32스텝, 1/8·1/16·1/32·1/16T, 스윙, 액센트, 초크, 호스트 동기화, 내부 클럭, MIDI 노트 36~43, Drag MIDI
- 스킨 5종: PS2 Night, Y2K Chrome, Digicore, Mix(기본), Liquid Chrome — 3D 크롬 아이콘(Y2K/Mix/Liquid)
- 창 크기 조절·기억, 프로젝트별 상태 저장(트랙 샘플, 패턴, 파라미터, 스킨)

## 4. 테스트 결과 (리눅스 작업 환경)
- DSP: 모든 모드/길이에서 정확한 길이, Hybrid 어택 샘플 단위 동일
- 호스트: 분류, 시퀀서 타이밍(샘플 단위 정확), 50/100/200% 길이, 오디션 4배 비율, 상태 저장, MIDI 내보내기, 재실행 시 재스캔 없음
- 스트레스(12,000개, 2코어): 약 3,800개/초, 중간 종료 후 이어서 완료, 재실행 로드 30~45ms, 지도 다시 그리기 약 11ms
- 맥·윈도우 CI 빌드 성공 (실제 DAW에서의 동작은 사용자 확인 필요)
